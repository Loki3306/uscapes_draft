# Model Checkpoints Directory

This directory is the local destination for trained model checkpoints generated during reproduction runs.

In accordance with scientific software standards, **pre-trained binary `.pt` files are not distributed in this repository**. The repository provides the complete model definitions, preprocessing pipelines, training procedures, and evaluation code required to reproduce the paper's experiments by training the models locally.

---

## Directory Organization

```text
checkpoints/
├── dtu/       # Local destination for DTU ContrastiveMatchNet models (generated by scripts/dtu/train_matchnet_loso.py)
└── kul/       # Local destination for KUL AAD-Conformer models (generated by scripts/kul/train_conformer_loso.py)
```

---

## 1. Generating DTU Checkpoints Locally

To train the 18 subject-specific `ContrastiveMatchNet` models under Leave-One-Subject-Out (LOSO) cross-validation:

```bash
python scripts/dtu/train_matchnet_loso.py \
    --data_dir data/dtu \
    --epochs 30 \
    --batch_size 64 \
    --lr 0.001
```

- **Output Destination**: `checkpoints/dtu/` (or `checkpoints/matchnet_S1.pt` through `matchnet_S18.pt`).
- **Expected Architecture**: `ContrastiveMatchNet` (EEGNet encoder: 2,320 params, AudioEncoder: 48,608 params, Total: 50,928 parameters).
- **Subsequent Step**: Once checkpoints are generated locally, run prediction export:
  ```bash
  python scripts/dtu/export_matchnet_predictions.py \
      --checkpoint_dir checkpoints/dtu \
      --out_csv matchnet_predictions.csv
  ```

## 2. Generating KUL Checkpoints Locally

### A. Base AAD-Conformer Decoding Checkpoints
To train the 16 subject-specific `AADConformer` models under LOSO cross-validation:

```bash
python scripts/kul/train_conformer_loso.py \
    --cache_dir data/processed_kul \
    --seed 1 \
    --epochs 40
```

- **Output Destination**: `checkpoints/kul/` (`model_S1.pt` through `model_S16.pt`).
- **Expected Architecture**: `AADConformer` (8 channels, 32 temporal filters, 64 spatial filters, embed_dim 64, 4 attention heads, 2 conformer layers; Total: 162,849 parameters).
- **Evaluation**: Run `scripts/kul/eval_selective_aad.py` or `scripts/kul/eval_falsification.py` against these checkpoints.

### B. Evidential Confidence Head Checkpoints (Multi-Task with Outlier Exposure)
To train the 16 multitask models equipped with the evidential confidence head:

```bash
python scripts/kul/train_conformer_multitask_loso.py \
    --cache_dir data/processed_kul \
    --seed 1 \
    --epochs 20
```

- **Output Destination**: `checkpoints/kul/` (fine-tuned models containing the 2,241-parameter late-fusion confidence head; Total: 165,090 parameters).
- **Evaluation**: Run `scripts/kul/eval_confidence_multitask.py` to evaluate AUROC (0.7337) and ECE (0.0998).

## 3. Stochastic Numerical Variance Note

The training procedures employ stochastic gradient descent (AdamW optimizer). Without fully hardware-pinned deterministic GPU seeds, fresh training runs will exhibit small, expected numerical variations:
- **DTU Baseline**: Historically reported at **69.02%**; canonical retraining yields **68.19%** across the 5,400 non-overlapping 10-s windows (see [docs/LIMITATIONS.md](../docs/LIMITATIONS.md)).
- **KUL Baseline**: Historically reported at Grand Mean **77.12% ± 9.99%** across 5 seeds. Individual runs reproduce the ~75–78% expected operating range.
