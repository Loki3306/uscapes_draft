# Result Scope & Provenance Audit

This document classifies every quantitative value presented in `final_reproduction_report.md` against the authoritative final paper specification.

---

## Classification Taxonomy
- **A. Explicitly reported in the final paper**: Number appears directly in the paper text, abstract, or primary tables.
- **B. Derived directly from a paper experiment**: Generated by running a paper experiment, but represents a stochastic rerun or local dataset evaluation rather than the exact historical paper constant.
- **C. An intermediate diagnostic used by the paper**: Internal diagnostic or sanity check discussed in the paper's narrative or methodology, but not a primary benchmark table entry.
- **D. An experiment not reported in the paper**: Additional metric, threshold point, or test that exists in repository scripts but is absent from the final manuscript.
- **E. From an older/newer research version**: Value belonging to a different iteration, preliminary run, or conflated with an alternative statistic.
- **F. Unknown provenance**: Unverified source.
