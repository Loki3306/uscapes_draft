**"Decision-Gated Auditory Attention Decoding from Low-Density EEG: Confidence-Conditioned Neural Inference for State-Aware Auditory Control"**

---

## Reproducibility Status Taxonomy

Every reported claim is tagged with one of the following authoritative statuses:
- **REPRODUCIBLE**: Directly runnable using existing scripts and documented inputs to obtain the exact or near-identical paper metric.
- **REPRODUCIBLE WITH STOCHASTIC VARIATION**: Executable procedure that reproduces the reported finding within expected stochastic training variance (optimizer initialization, mini-batch ordering).
- **REQUIRES TRAINING**: Procedurally complete. Does not include pre-trained binary weights; running the documented training script generates the required local model weights to evaluate the metric.
- **ARTIFACT VERIFIED**: Verified directly against preserved, uncompressed raw experimental trial summaries.
- **EXCLUDED**: Invalidated historical artifact or post-paper experiment intentionally omitted from the primary submission pipeline.

## Numerical Discrepancy Transparency Note

### DTU Baseline Accuracy: 69.02% vs. 68.19%
- **Manuscript Text**: Reports **69.02%** LOSO accuracy.
- **Historical Canonical Retraining**: Produced **68.19%** (3,682 / 5,400 windows correct) in `experiments/E0_canonical_result.md` (commit `aeb82b9`).
- **Cause**: ContrastiveMatchNet uses stochastic mini-batch sampling and SGD optimization. In the earliest experimental logs, optimizer seeds were not globally pinned across CUDA convolutions, introducing run-to-run numerical jitter of approximately $\pm 0.8\%$.
- **Scientific Integrity Decision**: We intentionally do not tamper with code, seeds, or evaluation scripts to cosmetically force `69.02%`. The experimental architecture, loss function, and evaluation protocol are identical.
